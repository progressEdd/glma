# Plan 03 — Score Breakdown in Search Output

## Objective

Extend all search output formatters to include graph score breakdown when `--graph` mode is active. When `--graph` is off, output matches v1.3 format exactly.

## Tasks

### Task 1: Add graph_enabled parameter to format functions

<read_first>
- src/glma/search/formatter.py — all four format functions and the dispatch function
</read_first>

<action>
Modify `src/glma/search/formatter.py` to add `graph_enabled: bool = False` parameter to all format functions and the dispatch function:

1. **`format_search_markdown`** — add `graph_enabled: bool = False` parameter. After the summary annotation line, when `graph_enabled` is True, add a scores annotation:
```python
if graph_enabled:
    lines.append(f"> *Scores: graph={result.graph_score:.2f}, keyword={result.keyword_score:.2f}, vector={result.vector_score:.2f}, combined={result.combined_score:.2f}*")
```

2. **`format_search_kv`** — add `graph_enabled: bool = False` parameter. After the existing `score:` line, when `graph_enabled` is True, add:
```python
if graph_enabled:
    lines.append(f"graph_score: {result.graph_score:.3f}")
    lines.append(f"keyword_score: {result.keyword_score:.3f}")
    lines.append(f"vector_score: {result.vector_score:.3f}")
```

3. **`format_search_json`** — add `graph_enabled: bool = False` parameter. In the scores dict, conditionally add the `graph` key:
```python
"scores": {
    "keyword": round(r.keyword_score, 4),
    "vector": round(r.vector_score, 4),
    **({"graph": round(r.graph_score, 4)} if graph_enabled else {}),
    "combined": round(r.combined_score, 4),
},
```

4. **`format_search_yaml`** — same pattern as JSON for the scores dict.

5. **`format_search_output`** — add `graph_enabled: bool = False` parameter and pass it through to each format function call:
```python
def format_search_output(
    results: list[SearchResult],
    output_format: str,
    query: str,
    search_mode: str,
    original_query: Optional[str] = None,
    rewritten_query: Optional[str] = None,
    graph_enabled: bool = False,
) -> str:
```
Update each dispatch call to pass `graph_enabled=graph_enabled`.
</action>

<acceptance_criteria>
- `src/glma/search/formatter.py` contains `graph_enabled: bool = False` in `format_search_markdown`, `format_search_kv`, `format_search_json`, `format_search_yaml`, and `format_search_output`
- `src/glma/search/formatter.py` contains `> *Scores: graph=` (markdown annotation when graph_enabled)
- `src/glma/search/formatter.py` contains `"graph": round(r.graph_score, 4)` (JSON/YAML scores when graph_enabled)

- When `graph_enabled=False`: `format_search_json` output `scores` dict has no `graph` key

- When `graph_enabled=True`: JSON output `scores` dict contains `graph` key
