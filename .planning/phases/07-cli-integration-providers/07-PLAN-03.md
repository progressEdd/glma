# Plan 03: Render Chunk Summaries in All Output Paths

## Objective
Make per-chunk AI summaries visible in all three output formats: export markdown, query output, and writer markdown. Remove the on-the-fly `generate_ai_summary()` function from export.py. This is the user-facing payoff — after running `glma index --summarize`, summaries appear everywhere.

## Tasks

### Task 3.1: Render chunk summaries in export.py

<read_first>
- 02-worktrees/glma/src/glma/export.py (full file — especially `_format_export_file` Chunks section around lines 130-150, and `generate_ai_summary` function)
- 02-worktrees/glma/src/glma/summaries.py (generate_rule_summary — the file-level summary function)
</read_first>

<action>
In `02-worktrees/glma/src/glma/export.py`, make these changes:

1. **Remove `generate_ai_summary()` function entirely** (lines ~28-82). This is the on-the-fly OpenAI file-level summarization. It's replaced by chunk summaries from the DB.

2. In `_format_export_file()`, in the Summary section (the block that starts with `# Summary`), replace the `if config.ai_summaries:` branch:

   **Before:**
   ```python
   if config.ai_summaries:
       ai_summary = generate_ai_summary(file_path, chunks, config.ai_base_url, config.ai_model)
       lines.append(ai_summary)
   else:
       rule_summary = generate_rule_summary(file_path, chunks, relationships)
       lines.append(rule_summary)
   ```

   **After:**
   ```python
   # File summary: rule-based always, enhanced with AI chunk summaries if available
   rule_summary = generate_rule_summary(file_path, chunks, relationships)
   lines.append(rule_summary)

   # If ai_summaries enabled, show AI chunk summary overview
   if config.ai_summaries:
       ai_chunks = [c for c in chunks if c.summary]
       if ai_chunks:
           lines.append("")
           lines.append("**AI Chunk Summaries:**")
           for c in ai_chunks[:10]:
               lines.append(f"- **{c.name}**: {c.summary}")
   ```

3. In `_format_export_file()`, in the Chunks section (the `for chunk in chunks:` loop), add chunk summary rendering:

   **Before** (the `if config.include_code:` block):
   ```python
   if config.include_code:
       lang_hint = ""
       ...
       lines.append(f"```{lang_hint}")
       lines.append(chunk.content)
       lines.append("```")
   else:
       lines.append(f"*(Code omitted. Signature: L{chunk.start_line}-L{chunk.end_line})*")
   ```

   **After:**
   ```python
   # Chunk summary (from DB — generated by `glma index --summarize`)
   if chunk.summary:
       lines.append(f"> *Summary: {chunk.summary}*")
       lines.append("")

   if config.include_code:
       lang_hint = ""
       ...
       lines.append(f"```{lang_hint}")
       lines.append(chunk.content)
       lines.append("```")
   else:
       if chunk.summary:
           # Summary already shown above, code omitted is implicit
           pass
       else:
           lines.append(f"*(Code omitted. Signature: L{chunk.start_line}-L{chunk.end_line})*")
   ```

</action>
