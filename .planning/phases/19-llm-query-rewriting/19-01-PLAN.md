### Task 2: Create search/rewriter.py with DEFAULT_REWRITE_PROMPT and rewrite_query function

<read_first>
- src/glma/summarize/providers.py (OpenAICompatibleProvider, SYSTEM_PROMPT, client pattern, constructor signature)
- src/glma/search/engine.py (SearchResult — no changes needed, just context)
</read_first>

<action>
Create new file `src/glma/search/rewriter.py` with:

1. **`DEFAULT_REWRITE_PROMPT`** constant string:
```python
DEFAULT_REWRITE_PROMPT = (
    "You are a code search assistant. Rewrite the user's query to be more effective "
    "at matching code documentation and summaries.\n\n"
    "Rules:\n"
    "- Expand abbreviations to full terms (auth → authentication, db → database, cfg → configuration)\n"
    "- Add likely descriptive terms that would appear in developer-focused code summaries\n"
    "- Preserve technical terms and exact identifiers (function names, class names, API paths)\n"
    "- Keep the original intent — do not add unrelated concepts\n"
    "- Use natural descriptive language about what code does (purpose, behavior, inputs, outputs)\n"
    "- Return ONLY the rewritten query string, no explanation"
)
```

2. **`rewrite_query()`** function with this exact signature:
```python
def rewrite_query(
    query: str,
    base_url: str,
    model: str,
    rewrite_prompt: Optional[str] = None,
    timeout: float = 15.0,
    max_tokens: int = 100,
) -> str:
```

Implementation:
- Import `Optional` from typing
- Try to import `OpenAI` from openai package (same pattern as `OpenAICompatibleProvider.__init__`)
- If ImportError, raise ImportError with message: `"Query rewriting requires the 'openai' package. Install with: pip install glma[ai]"`
- Create `OpenAI(base_url=base_url, api_key="not-needed")` client (same as providers.py)
- Use `rewrite_prompt` if provided, otherwise `DEFAULT_REWRITE_PROMPT`
- Call `client.chat.completions.create(model=model, messages=[{"role": "system", "content": system_prompt}, {"role": "user", "content": query}], max_tokens=max_tokens, timeout=timeout)`
- Return `response.choices[0].message.content.strip()`
- If response is empty string, return the original query
</action>

<acceptance_criteria>
- `src/glma/search/rewriter.py` exists and contains `DEFAULT_REWRITE_PROMPT` constant
- `src/glma/search/rewriter.py` contains `def rewrite_query(query: str, base_url: str, model: str, rewrite_prompt: Optional[str] = None, timeout: float = 15.0, max_tokens: int = 100) -> str:`
- `from glma.search.rewriter import rewrite_query, DEFAULT_REWRITE_PROMPT` succeeds
- `DEFAULT_REWRITE_PROMPT` contains the substring "Expand abbreviations"
- `DEFAULT_REWRITE_PROMPT` contains the substring "Return ONLY the rewritten query string"
</acceptance_criteria>
