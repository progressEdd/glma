# Plan 02 — Formatter Query Header Support

## Objective

Add original/rewritten query header display to all search output formatters. This handles the transparency requirement (REWR-04) so that users always see both their original query and the LLM-rewritten version.

## Tasks

### Task 1: Add query header to format_search_markdown

<read_first>
- src/glma/search/formatter.py (format_search_markdown function, full file)
</read_first>

<action>
Modify `format_search_markdown` to accept optional `original_query` and `rewritten_query` parameters:

Change signature from:
```python
def format_search_markdown(results: list[SearchResult]) -> str:
```
to:
```python
def format_search_markdown(
    results: list[SearchResult],
    original_query: Optional[str] = None,
    rewritten_query: Optional[str] = None,
) -> str:
```

Add header logic at the start of the function body (before the `if not results:` check):

```python
    lines: list[str] = []

    # Query header
    if original_query is not None:
        if rewritten_query is not None:
            lines.append(f'# Query: "{original_query}"')
            lines.append(f'# Rewritten: "{rewritten_query}"')
            lines.append("")
        else:
            lines.append(f'# Query: "{original_query}" (raw)')
            lines.append("")

    if not results:
        return "\n".join(lines)
```

Remove the existing `lines: list[str] = []` declaration (now at the top) and the `if not results: return ""` block (replaced by the new check above).

The rest of the function (file heading + code block loop) stays exactly the same.

Note: When `original_query` is None (backward compat — no rewrite info provided), the function behaves exactly as before, producing no header.
</action>

<acceptance_criteria>
- `format_search_markdown(results)` still works with just results (backward compatible)
- `format_search_markdown(results, original_query="auth", rewritten_query="authentication login")` produces output starting with `# Query: "auth"` followed by `# Rewritten: "authentication login"`
- `format_search_markdown(results, original_query="auth")` (no rewritten_query) produces `# Query: "auth" (raw)`
- `format_search_markdown([])` returns empty string `""` (no header for empty results with no query info)
- `format_search_markdown([], original_query="test")` returns query header with no results
</acceptance_criteria>
