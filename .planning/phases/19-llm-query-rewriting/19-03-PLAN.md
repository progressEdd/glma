### Task 2: Integrate rewrite step into search command flow

<read_first>
- src/glma/cli.py (the `search` function body — the full flow from flag validation through engine.search() call to output)
- src/glma/search/rewriter.py (rewrite_query function signature)
- src/glma/search/formatter.py (format_search_output updated signature with original_query, rewritten_query)
- src/glma/config.py (load_summarize_config function)
</read_first>

<action>
In the `search` function body, after the existing "Load search config" block and before "Instantiate embedding provider", add the rewrite logic:

```python
    # Query rewriting (unless --raw)
    rewritten_query = None
    if not raw:
        from glma.config import load_summarize_config
        from glma.search.rewriter import rewrite_query

        # Build summarize overrides for rewrite provider
        summarize_overrides: dict = {}
        if summarize_provider:
            summarize_overrides["provider"] = summarize_provider
        if summarize_model:
            summarize_overrides["model"] = summarize_model
        if ai_url:
            summarize_overrides["base_url"] = ai_url

        summ_cfg = load_summarize_config(repo_root_path, summarize_overrides)

        try:
            rewritten_query = rewrite_query(
                query=query_text,
                base_url=summ_cfg.base_url,
                model=summ_cfg.model,
                rewrite_prompt=search_cfg.rewrite_prompt,
            )
        except Exception as e:
            sys.stderr.write(f"Rewrite failed: {e}. Using raw query.\n")
            rewritten_query = None
```

Then modify the `engine.search()` call to use the rewritten query when available:

Change from:
```python
        results = engine.search(query_text, mode=search_mode)
```
to:
```python
        effective_query = rewritten_query if rewritten_query is not None else query_text
        results = engine.search(effective_query, mode=search_mode)
```

Then modify the `format_search_output()` call to pass query info:

Change from:
```python
        formatted = format_search_output(results, output_format, query_text, search_mode)
```
to:
```python
        formatted = format_search_output(
            results, output_format, effective_query, search_mode,
            original_query=query_text,
            rewritten_query=rewritten_query,
        )
```

Note: When `raw=True`, `rewritten_query` stays `None`, and `effective_query == query_text`. The formatter receives `original_query=query_text, rewritten_query=None` which produces the "(raw)" label.
</action>

<acceptance_criteria>
- `src/glma/cli.py` `search` function imports `rewrite_query` from `glma.search.rewriter`
- `src/glma/cli.py` `search` function imports `load_summarize_config` from `glma.config`
- When `--raw` is not set: `rewrite_query()` is called with `query_text`, summarizer config `base_url`/`model`, and `search_cfg.rewrite_prompt`
- When `--raw` is set: `rewrite_query()` is NOT called, `rewritten_query` stays `None`
- On rewrite exception: `sys.stderr` contains "Rewrite failed:", `rewritten_query` is set to `None`, search proceeds with `query_text`
- `engine.search()` receives `rewritten_query` if available, else `query_text`
- `format_search_output()` receives `original_query=query_text` and `rewritten_query=rewritten_query`
</acceptance_criteria>
