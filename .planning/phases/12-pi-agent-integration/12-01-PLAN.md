### Task 2: Add preset resolution to config.py

<read_first>
- 02-worktrees/glma/src/glma/config.py
- 02-worktrees/glma/src/glma/models.py
</read_first>

<action>
In `config.py`, modify `load_summarize_config()` to resolve preset names before creating `SummarizeConfig`.

1. After loading `file_config` and building `merged` dict (but before `SummarizeConfig(**merged)`), add preset resolution:

```python
from glma.models import PROVIDER_PRESETS

# Load custom providers from [summarize.providers] section
custom_providers = {}
if config_path.exists():
    with open(config_path, "rb") as f:
        raw = tomllib.load(f)
    summarize_section = raw.get("summarize", {})
    custom_providers = summarize_section.get("providers", {})

# Merge custom providers with built-in presets
all_presets = {**PROVIDER_PRESETS, **custom_providers}

# Resolve provider preset to base_url and model
provider_name = merged.get("provider", "local")
if provider_name in all_presets:
    preset = all_presets[provider_name]
    # Preset fills defaults; explicit CLI flags override
    if "base_url" not in merged or merged.get("base_url") == "http://localhost:1234/v1":
        merged["base_url"] = preset["base_url"]
    if "model" not in merged or merged.get("model") == "default":
        merged["model"] = preset.get("model", "default")

merged["custom_providers"] = custom_providers
```

2. The resolution priority is:
   - `--summarize-provider <preset>` fills defaults from preset
   - `--ai-url` (if we add it) or `base_url` from CLI overrides preset
   - `--summarize-model` overrides preset model
   - Explicit flags always win over preset defaults

3. Note: the check for `"base_url" not in merged` handles the case where no explicit base_url was provided. The default value check handles the case where Pydantic default was already set. Since we're resolving BEFORE Pydantic validation, we check if the merged dict has an explicit override.

4. Do NOT add `--ai-url` flag — per CONTEXT.md D-11, `--summarize-model` and base_url in config override preset defaults. The existing `SummarizeConfig.base_url` field serves this purpose via `.glma.toml` or we can add `--ai-url` to CLI if desired. Keep it simple: users set `base_url` in `[summarize]` section of `.glma.toml` to override preset URL.
</action>

- When `provider="ollama"` and explicit `base_url="http://custom:9999/v1"` are both passed, the explicit URL wins
